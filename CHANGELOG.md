# Changelog

## 0.2.0 - 2026-10-16

- Added Horizontal, Vertical, and Custom mask region layouts.
- Added grayscale custom masks: white selects Region A, black selects Region B.
- Applied boundary feathering to uploaded custom masks.
- Preserved the existing Horizontal layout as the default.

## 0.1.0 - 2026-10-12

- Initial experimental release.
- Added two-pass left/right Anima LoRA separation.
- Added adjustable LoRA strengths, boundary position, and feather width.
- Added generation metadata for patch counts.
- Added dependency-free core tests.
